캡처는 실제 Flutter 위젯을 실행해 생성했습니다. 회원 API와 TMDB 응답은 각 상태를 재현할 수 있도록 테스트 데이터를 주입했습니다.

## 트러블슈팅

입력값을 바꾼 뒤 늦게 도착한 응답이 화면에 표시되는 문제를 막기 위해 요청 번호와 현재 입력의 변경 이력을 비교했습니다. 중복이었던 값은 별도로 저장해 같은 문자열을 다시 입력하면 요청 없이 에러 상태를 복원했습니다.

## 6주차 회고

버튼의 통신 상태와 입력 검증 상태를 분리했습니다. 평점 화면은 회원의 평점 목록을 먼저 받아 영화 ID로 상세 정보를 조회하고, 각 결과를 Loading, Empty, Error, Success로 나눠 표시했습니다.
